혈당 안정화 가이드
식후 졸림·허기짐의 진짜 원인 — 이 다이어리의 "식후 에너지" 체크가 혈당 스파이크 감지기입니다
혈당 스파이크가 왜 문제인가?
탄수화물 섭취 → 혈당 급상승 → 인슐린 과분비 → 혈당 급락 → 졸림·허기짐·집중력 저하·단것 갈망이 반복됩니다. 장기적으로 반복되면 인슐린 저항성 → 만성 염증 → 당뇨 전단계로 이어질 수 있습니다.
혈당을 낮추는 식사 순서 — 같은 음식도 순서만 바꾸면 스파이크 최대 75% 감소

혈당지수(GI) 식품 가이드
같은 칼로리도 GI에 따라 혈당·인슐린 반응이 달라집니다
GI(혈당지수)란?
음식 섭취 후 혈당이 오르는 속도를 0~100으로 수치화한 것. 낮을수록 천천히 소화·흡수되어 인슐린 급등 없이 에너지가 고르게 공급됩니다. 기능의학에서는 GI 55 이하를 목표로 식단을 구성합니다.

왜 수면을 기록해야 할까?
수면은 단순한 휴식이 아닙니다. 수면 중 우리 몸은 독소 제거(글림프 시스템), 호르몬 재설정, 장 점막 복구, 면역 강화를 수행합니다.
수면 패턴을 추적하면 염증, 혈당 조절, 장 건강, 기분과의 연결고리를 직접 확인할 수 있습니다.

🍽️ 음식 → 수면의 질
저녁 식사 후 2-3시간 내에 특정 음식(글루텐, 유제품, 설탕)을 먹었을 때 깊은 수면이 줄어드는 패턴을 발견할 수 있음
⏰ 수면 시간과 장 건강
7시간 미만 수면 → 다음날 장 투과성 증가, 소화 불량, 더부룩함 악화. 이 다이어리와 함께 패턴 확인 가능
📈 수면과 혈당
수면 부족 시 코르티솔 상승 → 혈당 스파이크 → 다음날 설탕·탄수화물 갈망. 식욕 조절 실패의 원인
🦠 수면과 마이크로바이옴
수면 리듬이 깨지면 장내세균 다양성 감소. 특히 유익균(락토바실러스, 비피도박테리움) 비율 저하
⚠️ 수면을 방해하는 것들
• 취침 3시간 내 음식 섭취 (특히 당분)
• 카페인 (오후 2시 이후)
• 블루라이트 (자기 1시간 전 스크린)
• 알코올 (REM 수면 억제)
• 스트레스 → 코르티솔 상승 → 입면 방해
• 마그네슘 결핍 (신경 흥분 유지)
✅ 수면의 질을 높이는 방법
• 취침·기상 시간 일정하게 유지
• 마그네슘 글리시네이트 취침 전 복용
• 침실 온도 18-20°C 유지
• 저녁 Zone 2 운동 (취침 3시간 전)
• 취침 전 루틴 (독서, 스트레칭, 명상)
• 오메가-3 복용으로 염증 감소
기록 방법 — 이 다이어리에서
수면 시간(hrs)을 기록하고 Quality 1-5로 주관적 수면의 질을 평가하세요. 2주 이상 데이터가 쌓이면 어떤 날 잘 잤는지, 전날 무엇을 먹었는지, 스트레스 수준이 어땠는지 패턴이 보이기 시작합니다. 특히 Bristol Type + Sleep Quality를 함께 보면 장-뇌-수면 축의 연결을 직접 확인할 수 있습니다.

• 유발 식품 제거 (이 다이어리로 추적!)

📅 기록 팁
매일 같은 시간대에 확인하세요. 아침 첫 배변이 가장 정보가 많습니다. 전날 저녁 식사와 함께 비교하면 패턴이 보입니다.
🎯 목표
하루 1-2회, Type 3-4 형태가 이상적입니다. 3일 이상 Type 1-2이거나 하루 3회 이상 Type 6-7이면 전문가 상담을 권합니다.
🔗 연결 지표
Bristol 변화 + 먹은 음식 + 스트레스 수준을 함께 보세요. 특정 음식 48-72시간 후 변화가 나타나는 경우가 많습니다.

🧘 5분 바디스캔 명상 — 처음 시작하는 분께 눈 감고 / 조용한 곳 / 5분
① 자리잡기
눕거나 앉아서 눈을 감는다. 지금 이 순간 몸이 바닥에 닿는 느낌에 집중
② 호흡 확인
3번 깊게 복식호흡. 들이쉴 때 배가 나오고 내쉴 때 들어가는 것만 본다
③ 발부터 스캔
발끝 → 발목 → 종아리 → 무릎 순서로 각 부위의 감각을 10초씩 느낀다
④ 위로 이동
허벅지 → 배 → 가슴 → 어깨 → 목 → 얼굴. 긴장된 곳은 내쉬며 이완
⑤ 마무리
손발을 천천히 움직이고 눈을 뜬다. 지금 느낌을 다이어리 Meditation란에 기록
🧠 명상이 장에 미치는 효과
미주신경 자극 → 장 연동운동 활성화
코르티솔 감소 → 장 점막 투과성 정상화
소화 효소 분비 증가 (이완 상태에서만 작동)
장내세균 다양성 증가 (스트레스 시 dysbiosis 악화)
* 식사 전 3분 호흡만으로도 소화 개선 효과
📋 처음 시작하는 분께 — 2주 플랜
1주차: 복식호흡 5분 × 매일 (아침 기상 직후)
2주차: 복식호흡 + 4-7-8 취침 전 4사이클
3주차부터: 바디스캔 추가, 식사 전 박스 호흡

앱 추천: Insight Timer (무료) · Calm · 마보
